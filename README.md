# 🎮 Hangman Game (Python)

## 📌 Project Overview
This is a simple text-based Hangman game developed using Python. The player guesses a hidden word one letter at a time within a limited number of attempts.

## 🚀 Features
- Random word selection
- User input handling
- Limited attempts (6 chances)
- Real-time word display updates
- Win/Lose condition handling

## 🛠️ Technologies Used
- Python
- Concepts: random module, while loop, if-else, strings, lists

## 🎯 How to Play
1. Run the Python file
2. Guess one letter at a time
3. You have 6 incorrect attempts
4. Guess the full word before attempts run out
